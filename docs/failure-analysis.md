# Failure Analysis

The benchmark emits a structured failure taxonomy:

- INSUFFICIENT_EVIDENCE
- LOW_SOURCE_DIVERSITY
- CONSTRAINT_VIOLATION
- UNSUPPORTED_CLAIM
- RISK_MISSED
- POOR_RANKING
- BUDGET_EXHAUSTED
- TOOL_FAILURE
- STRUCTURED_OUTPUT_FAILURE
- REPLAY_MISS

`benchmark.html` exposes failure counts and representative examples. The deterministic verifier surfaces inspectable issues before a recommendation reaches evaluation.
